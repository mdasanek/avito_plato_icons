# Plato — Pixel Lab

Веб-редактор пиксельных иконок. Загрузка SVG или PNG размером **100 × 100 px**, пикселизация с шагом **5 или 10 px**, экспорт **PNG и настоящего векторного SVG**. Прозрачность сохраняется. Все файлы обрабатываются локально в браузере, без загрузки на сервер.

## Разработка

Требуется Node.js 20 или новее. У приложения нет внешних библиотек и серверных сервисов.

```sh
npm ci
npm start
```

Сервер слушает порт 4173. `PORT=8080 npm start` меняет порт.

## Проверки

```sh
npx playwright install --with-deps chromium
npm test
npm run build
```

При наличии `/usr/bin/chromium` тесты используют установленный Chromium. Проверяются загрузка обоих форматов, выбор шага, векторный экспорт, размеры и прозрачность PNG, совпадение PNG и SVG, ошибки файлов и мобильная версия.

## Публикация

Содержимое `dist/` после `npm run build` — полностью автономный статический сайт; подходит для GitHub Pages, Netlify, Vercel или любого HTTPS-хостинга. Сборка не использует сторонние шрифты, CDN, внешние API или секреты.

Для GitHub Pages подготовлена ветка `gh-pages` с готовыми файлами. В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите **gh-pages / (root)** и нажмите **Save**. После успешного развертывания GitHub покажет публичную ссылку.

Для обновления опубликованного сайта соберите приложение и опубликуйте содержимое `dist/` в `gh-pages`. Исходный код находится в ветке `pixel-lab-site`.

Для проверки production-сборки: `SERVE_DIST=1 npm start`.

## Как устроена пикселизация

Цвет каждой клетки — средний цвет области исходного изображения с учетом альфа-канала. Шаг 5 px дает сетку 20 × 20, шаг 10 px — 10 × 10. Размер выгрузки всегда 100 × 100 px. PNG создается из Canvas, SVG содержит прямоугольники с цветом и прозрачностью; растр внутрь SVG не встраивается. Сетка служит только для просмотра и не попадает в выгрузку.

SVG поддерживает статичные векторные элементы, встроенные стили и внутренние ссылки. Внешние изображения, шрифты, скрипты и анимация не поддерживаются. Максимальный размер входного файла — 5 МБ. Файлы неподходящего размера отклоняются, исходная иконка при ошибке сохраняется.
